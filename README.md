# Grow Right
Grow Right is a Python based plant recommendation app system designed to help users determine whether a specific plant is suitable for a particular city in Saudi Arabia.

The program compares a plant's environmental requirements against climate data from selected Saudi cities and provides a suitability score along with detailed planting instructions.
## Features:
### Plant Suitability Analysis:

Users can select a plant and a city, and the system will calculate how suitable the plant is for that location.

The evaluation is based on:

1-Temperature preference
2-Humidity preference
of the Preferred growing season of the city

### Growing Guide:

For every plant in the database, the application provides:
1-Optimal temperature range
2-Humidity requirement
3-Preferred growing season
4-Soil type
4-Watering schedule
5-Sun exposure requirement
6-Recommended growing location (Indoor/Outdoor)
